# Set up your first breakdown

No HTML, CSS or programming knowledge is needed.

1. Open **Tools > Auto Kanji Breakdown > Settings**.
2. Choose the **Note type** used by your Japanese cards. In Browse, inspect one of
   your notes if you are unsure which type it uses.
3. Under **Japanese fields**, tick the fields containing the Japanese text you
   want analysed. Select more than one if useful; Move up/down sets their order.
4. Keep **Create a new dedicated field (recommended)** for the breakdown data.
5. Under **Display breakdown on**, keep **Back** checked and Front unchecked so
   the breakdown does not reveal information before your answer.
6. Keep **Automatically keep breakdowns updated** and **Generate breakdowns for
   existing notes now** checked for first setup.
7. Choose **Review changes...**, read the summary and press **Apply**.

Your Japanese text is kept. Existing-note generation runs with progress and can be
cancelled. Completed work remains undoable. Repeat for other note types.

## Choices worth knowing

- **Breakdown data field:** let the add-on create a dedicated field. Do not put
  handwritten content in it. An existing field is accepted only if its contents
  can safely be used for generated breakdowns.
- **Appearance / Theme:** Blue is the initial default (formerly called Classic).
  Saved themes are respected. The adjacent Apply button changes all configured
  breakdown displays without applying pending field choices.
- **Automatic kanji data updates:** a separate option for periodic official-source
  checks, not the switch for keeping your notes updated.
- **? buttons:** open short local explanations. **Help & Guide** has common tasks.

Reopening an unchanged note type does not force another full regeneration. Changing
Japanese fields, their order, the breakdown field or enabling a disabled setup
recommends regenerating existing notes. Explicit choices in the open window are kept.
