# Installation

1. Download the latest beta `.ankiaddon` from the [GitHub Releases page](https://github.com/NikhilDhanda/Auto-Kanji-Breakdown/releases).
2. Open it with desktop Anki, or choose **Tools > Add-ons > Install from file** and select it.
3. Restart Anki.
4. Open **Tools > Auto Kanji Breakdown > Settings** and follow [setup](setup.md).

Download the attached **`.ankiaddon` asset**, not GitHub's **Source code (zip)**.
The source ZIP is for development and cannot be installed as the add-on.
If no beta asset is listed, a download is not available yet.

## AnkiWeb

AnkiWeb installation is not available yet.

## Updating

Download the new `.ankiaddon` from Releases, install it through Anki and restart.
For updated card styling, open Settings and use theme **Apply**, or review and apply
the same settings. Regeneration refreshes note information, not the display code.
