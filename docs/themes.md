# Themes

Choose **Tools > Auto Kanji Breakdown > Settings**, select **Appearance / Theme**,
then press the **Apply** button beside it. You will see **Theme applied**.

| Theme | Appearance |
| --- | --- |
| Light | Pale neutral surfaces |
| Dark | Charcoal surfaces |
| Blue | Indigo, the original Classic palette |
| Brown | Warm dark brown |
| Matcha | Pale green |
| Matcha Dark | Deep green |
| Sakura | Pale pink |
| Sakura Dark | Dark plum, the original Sakura palette |

Theme Apply updates all configured breakdown displays in the collection. It does
not regenerate notes or apply unrelated pending field selections. The change is
undoable in Anki. Sync to carry it to mobile.

Themes affect Auto Kanji Breakdown, not Anki's application theme. Every palette
uses the same layout and interaction. Existing theme choices are preserved.
