# Changelog

## v0.9.0-beta.1

- Automatic kanji breakdown generation for configured desktop note types and Japanese fields.
- Recursive component trees, readings, meanings, strokes, available frequency, radicals and positions.
- Existing-deck setup with arbitrary field names and chosen card sides, without HTML/CSS editing.
- Support for Yomitan/AnkiConnect note-creation workflows.
- Synced mobile/offline display, with desktop regeneration needed after mobile text edits.
- Eight themes and global theme Apply.
- Current-note, selected-note and bulk manual regeneration with useful completion summaries.
- Optional background official-source updates and a bundled offline fallback.
- Safe cleanup, optional verified field deletion and optional downloaded-data removal.
- Offline Sources/licensing panel, About, first-run onboarding and Help & Guide.

See the [user guides](docs/README.md) for setup and everyday use.
