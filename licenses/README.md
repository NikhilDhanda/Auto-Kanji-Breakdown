# Bundled upstream notices

Retrieved 2026-09-10 for offline redistribution with Auto Kanji Breakdown.
These third-party files retain their upstream licences, separately from project software.

`sources.json` records download URLs and SHA-256 hashes of exact retrieved bytes.
CC plain-text licences came from the official Creative Commons
`creativecommons/cc-legal-tools-data` repository because the public website refused
automated text downloads. Canonical licence URLs are recorded too.
Root `LICENSE` is the unchanged canonical GNU AGPL v3 text from gnu.org.
`AUTHORS` selects AGPL-3.0-or-later for original software. Upstream data is not AGPL.

`KanjiVG-source-notice.txt` preserves the comment text from `kanji/079c1.svg` in
`kanjivg-20250816-main.zip`, omitting comment delimiters. Archive SHA-256:
`69a2944ec1183086fdee5ba9c1f48bc306b867480a95b2f337f3203bf50689a3`.

HTML files preserve upstream bytes. Text is readable offline; external navigation,
images or styles may need a connection. Runtime never loads these pages or their
external resources. See [third-party licensing](../THIRD_PARTY_LICENSES.md).
